# Официальные релизы Haper Forge

Здесь публикуются только готовые артефакты продуктов Haper Forge: установочные
комплекты, контрольные суммы, подписи, состав версии и примечания. Исходный код
продуктов в этом репозитории не публикуется.

## Продукты

| Продукт | Установка |
|---|---|
| Narvelium | Linux, Docker Compose, автономный комплект |
| Opselium Server | Linux, PostgreSQL 16, Caddy, автономный комплект |
| Portelium | Linux-сервер и отдельные Windows-компоненты |
| CCTV Viewer | Linux/amd64 bundle, Windows-компоненты отдельно |

## Как проверять загрузку

1. Скачайте артефакт из раздела Releases.
2. Сверьте SHA-256 с файлом `.sha256` и с карточкой версии на сайте.
3. Проверьте подпись `SHA256SUMS.sig` открытым ключом с официального сайта.
4. Устанавливайте только на чистой тестовой машине.

Официальная страница загрузок: https://www.haperforge.ru/downloads/

Торрент-раздача использует те же байты и тот же SHA-256. Выбор канала не меняет
лицензию, состав редакции и условия активации.

## Что не публикуется

- исходный код;
- внутренние ключи, токены и конфигурации;
- персональные данные и данные заказчиков;
- тестовые сборки без приёмки.

Каждая версия привязана к полному SHA источника и проходит проверку состава,
контрольных сумм и отсутствия секретов.
